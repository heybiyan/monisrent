# monis.rent — Workspace Builder

A 2D interactive workspace setup builder web application for [monis.rent](https://monis.rent). Users can assemble custom desk setups with chairs, monitors, computers, and accessories, viewing real-time visual compositing and weekly rental price summaries.

## 🚀 Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context (`BuilderContext`)
- **Deployment:** Vercel

```bash

```
